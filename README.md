# week8-GitCode-Structure

##  Project Description
This project is a practice for Git workflow and code structure.  
It includes working with branches, commits, merges, and pull requests.

## Topics Covered
- git init
- commit
- branch
- merge
- pull request

##  Git Workflow
1. [chore] initialize repository using `git init`
2. [feat] create commits with meaningful messages
3. [feat] create a feature branch named `feature-change-body-background-color`
4. [style] change background color in `search_realtime.css`
5. [merge] merge `feature-change-body-background-color` branch into `main` branch
